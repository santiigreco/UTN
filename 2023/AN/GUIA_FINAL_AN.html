⚡ Diferencia clave: Ajuste vs Interpolación

Ajuste:

  • La curva NO pasa por todos los puntos
  • Minimiza \( S = \sum_i [y_i - f(x_i)]^2 \)
  • Para datos con ruido o error experimental
  • Grado \( N \leq n-1 \)

Interpolación:

  • El polinomio pasa exactamente por todos los puntos
  • \( P(x_i) = y_i \) para todo \(i\)
  • Para datos exactos o conocidos
  • Grado \( = n - 1 \)
⚠️ Trampa clásica: Confundir ajuste con interpolación. Datos con dispersión → Ajuste. Datos exactos que todos deben cumplirse → Interpolación.

1. Raíces de Funciones

Bisección · Newton-Raphson · Punto Fijo
Concepto base

¿Qué es una raíz?

Una raíz o cero de \(f(x)\) es un valor \(x^*\) tal que \(f(x^*) = 0\). Los métodos numéricos construyen sucesiones \(\{x_n\}\) que convergen a \(x^*\).

Problema general $$\text{Hallar } x^* \text{ tal que } f(x^*) = 0$$
Teorema de Bolzano: Si \(f\) es continua en \([a,b]\) y \(f(a)\cdot f(b) < 0\), entonces \(\exists\, c \in (a,b)\) tal que \(f(c)=0\).
Bisección

1.1 Método de Bisección

Condiciones

Requisitos

  • \(f(x)\) continua en \([a, b]\)
  • \(f(a) \cdot f(b) < 0\) (Bolzano)
  • Si hay raíz de multiplicidad par, Bolzano no se cumple aunque exista raíz
Error y Convergencia

Análisis

Convergencia lineal (lenta pero segura). En cada paso, el intervalo se divide a la mitad:

Cota de error en la iteración n $$|e_n| \leq \frac{b - a}{2^n}$$
Iteraciones necesarias para tolerancia ε $$n \geq \log_2\!\left(\frac{b - a}{\varepsilon}\right)$$
\(\varepsilon\) deseadoIntervalo \([0,1]\)Intervalo \([0,2]\)

Newton-Raphson

1.2 Método de Newton-Raphson

Condiciones

Requisitos

  • \(f(x)\) diferenciable en el entorno de \(x^*\)
  • \(f'(x_n) \neq 0\) en cada iterado
  • \(x_0\) suficientemente cerca de \(x^*\)
  • Si \(f'(x^*)=0\) (raíz múltiple), la convergencia baja a lineal
Convergencia

Análisis

Convergencia cuadrática cuando \(f'(x^*) \neq 0\):

Orden cuadrático de error $$e_{n+1} \approx \frac{f''(x^*)}{2\,f'(x^*)}\,e_n^2$$

Punto Fijo

1.3 Método de Punto Fijo

Teorema de Convergencia

Condición necesaria y suficiente

La iteración \(x_{n+1} = g(x_n)\) converge si:

  • \(g\) continua en \([a,b]\) y \(g(x) \in [a,b]\) para todo \(x \in [a,b]\)
  • \(\boldsymbol{|g'(x)| < 1}\) para todo \(x \in [a,b]\) — condición de contracción
Error en la iteración n (cota) $$|e_n| \leq \frac{|g'|^n}{1-|g'|}\,|x_1 - x_0|$$
Si \(|g'(x^*)| > 1\) → diverge. Hay que reformular \(f(x)=0\) para obtener otra \(g(x)\).

2. Ajuste de Funciones

Cuadrados Mínimos Lineal · No Lineal
Concepto base

Cuadrados Mínimos

Dado un conjunto de \(n\) pares \((x_i, y_i)\), se busca la función \(f(x)\) que minimice la suma de cuadrados de residuos:

Función objetivo a minimizar $$S = \sum_{i=1}^{n} \left[y_i - f(x_i)\right]^2 \quad\longrightarrow\quad \text{mínimo}$$
Ajuste Lineal

Recta de regresión: \(f(x) = a_0 + a_1 x\)

Imponiendo \(\partial S/\partial a_0 = 0\) y \(\partial S/\partial a_1 = 0\), se obtiene el sistema normal:

Sistema normal (2 ecuaciones, 2 incógnitas) $$\begin{cases} n\,a_0 + \left(\sum x_i\right) a_1 = \sum y_i \\[6pt] \left(\sum x_i\right)a_0 + \left(\sum x_i^2\right) a_1 = \sum x_i y_i \end{cases}$$
Fórmulas directas $$a_1 = \frac{n\sum x_i y_i - \sum x_i \sum y_i}{n\sum x_i^2 - \left(\sum x_i\right)^2}, \qquad a_0 = \bar{y} - a_1\,\bar{x}$$
Verificación: La suma de residuos \(\sum r_i = \sum(y_i - f(x_i)) \approx 0\) siempre (propiedad del sistema normal).
Linealización

Modelos no lineales comunes

Modelo originalTransformaciónVariables linealizadas
\(y = a\,e^{bx}\)\(\ln y = \ln a + b\,x\)\(Y=\ln y,\; X=x,\; A=\ln a\)
\(y = a\,x^b\)\(\ln y = \ln a + b\ln x\)\(Y=\ln y,\; X=\ln x\)
\(y = \dfrac{1}{a+bx}\)\(\dfrac{1}{y} = a + bx\)\(Y=1/y,\; X=x\)

📊 Coeficiente de determinación \(R^2\)

$$R^2 = 1 - \frac{\displaystyle\sum_{i=1}^n \left[y_i - f(x_i)\right]^2}{\displaystyle\sum_{i=1}^n \left(y_i - \bar{y}\right)^2}$$

\(R^2 = 1\) → ajuste perfecto. \(R^2 = 0\) → el modelo no explica nada. En la práctica, \(R^2 > 0.95\) es un buen ajuste.

3. Interpolación de Funciones

Lagrange · Newton (DD) · Splines · Hermite
Unicidad

Teorema fundamental

Dados \(n\) puntos \((x_0,y_0),\ldots,(x_{n-1},y_{n-1})\) con los \(x_i\) distintos, existe un único polinomio de grado \(\leq n-1\) que pasa por todos ellos.

$$\exists!\; P_{n-1}(x) \text{ tal que } P_{n-1}(x_i) = y_i \quad \forall\,i = 0,\ldots, n-1$$
Lagrange

3.1 Interpolación de Lagrange

Fórmula

Funciones base y polinomio

Función base de Lagrange i-ésima $$L_i(x) = \prod_{\substack{j=0 \\ j\neq i}}^{n-1} \frac{x - x_j}{x_i - x_j}$$
Polinomio interpolador $$P(x) = \sum_{i=0}^{n-1} y_i\, L_i(x)$$

Propiedad clave: \(L_i(x_i) = 1\) y \(L_i(x_j) = 0\) para \(j \neq i\).

Newton (DD)

3.2 Interpolación de Newton — Diferencias Divididas

Fórmula

Forma de Newton y Algoritmo de Horner

Diferencia dividida de orden k $$f[x_i,\ldots,x_{i+k}] = \frac{f[x_{i+1},\ldots,x_{i+k}] - f[x_i,\ldots,x_{i+k-1}]}{x_{i+k} - x_i}$$
Polinomio de Newton (coeficientes = primera diagonal de la tabla DD) $$P(x) = a_0 + a_1(x-x_0) + a_2(x-x_0)(x-x_1) + \cdots + a_{n-1}\prod_{j=0}^{n-2}(x-x_j)$$
Ventaja: Al agregar un nuevo punto, solo se calcula una nueva columna en la tabla. No se recalcula todo.
Splines Cúbicos

3.3 Splines Cúbicos Naturales

Condiciones

Para n puntos → n-1 splines cúbicos

Cada tramo: \(S_i(x) = a_i + b_i(x-x_i) + c_i(x-x_i)^2 + d_i(x-x_i)^3\). Condiciones:

CondiciónCantidad
Interpolación en ambos extremos de cada tramo\(2(n-1)\)
Continuidad de \(S'\) en nodos interiores\(n-2\)
Continuidad de \(S''\) en nodos interiores\(n-2\)
Frontera natural: \(S''(x_0) = S''(x_{n-1}) = 0\)\(2\)
TOTAL\(4(n-1)\) ✅
Fenómeno de Runge: Con muchos puntos equiespaciados, el interpolador polinomial de alto grado oscila enormemente en los extremos. Los Splines lo evitan.

📊 Error de interpolación

Término de error de Lagrange (para algún ξ ∈ [x₀, xₙ₋₁]) $$E(x) = f(x) - P(x) = \frac{f^{(n)}(\xi)}{n!}\,\prod_{i=0}^{n-1}(x - x_i)$$

El error depende de la \(n\)-ésima derivada de \(f\) y de la distancia a los nodos. Más puntos no siempre reducen el error.

Bisección — Algoritmo paso a paso
Hallar raíz de f(x) = 0 en [a, b] con tolerancia ε
  1. 1
    CONDICIÓN INICIAL: Verificar Bolzano: \(f(a)\cdot f(b) < 0\). Si no, el método no aplica en este intervalo.
  2. 2
    COTA PREVIA: Calcular \(n \geq \log_2\!\left(\dfrac{b-a}{\varepsilon}\right)\) para saber cuántas filas tendrá la tabla.
  3. 3
    FÓRMULA ITERATIVA:
    $$\boldsymbol{c = \frac{a + b}{2}}$$
  4. 4
    DECISIÓN: Evaluar \(f(c)\):
    • Si \(f(a)\cdot f(c) < 0\) → raíz en \([a, c]\) → actualizar \(b \leftarrow c\)
    • Si \(f(c)\cdot f(b) < 0\) → raíz en \([c, b]\) → actualizar \(a \leftarrow c\)
    • Si \(f(c) = 0\) → ¡raíz exacta!
  5. 5
    CRITERIO DE PARADA: Detener si \(|b-a| < \varepsilon\) o \(|f(c)| < \varepsilon\).
  6. 6
    REPETIR pasos 3–5 con el nuevo intervalo.
    La raíz aproximada es el último valor de c.
⚠️ CHECKLIST DE TRAMPAS — Bisección
  • 🚨
    No verificar Bolzano. Si \(f(a)\cdot f(b) > 0\), el método no aplica. Puede haber un número par de raíces o ninguna.
  • 🚨
    Confundir el criterio de actualización. El nuevo intervalo es aquel donde el producto de signos en los extremos sea negativo.
  • ⚠️
    Arrastrar errores de redondeo. Guardar todos los decimales posibles en cada c. No redondear intermedios.
  • 💡
    Calcular las iteraciones necesarias antes de empezar. \(n \geq \log_2((b-a)/\varepsilon)\) te dice exactamente cuántas filas necesitás.

Newton-Raphson — Algoritmo paso a paso
Hallar raíz con aproximación inicial x₀
  1. 1
    CONDICIÓN INICIAL: Calcular \(f'(x)\) analíticamente. Elegir \(x_0\) en zona donde \(f'(x_0) \neq 0\).
  2. 2
    FÓRMULA ITERATIVA:
    $$\boldsymbol{x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}}$$

  4. 4

  5. 5
    REPETIR con \(x_n \leftarrow x_{n+1}\).
⚠️ CHECKLIST DE TRAMPAS — Newton-Raphson
  • 🚨
    Calculadora NO en radianes. Si f contiene sen, cos, tan → verificar que esté en modo RADIANES.
  • 🚨
    Derivar mal \(f'(x)\). Un error en f' hace que TODAS las iteraciones sean incorrectas.
  • 🚨
    Dividir por cero. Si \(f'(x_n)=0\) el método falla. Ocurre con raíces de multiplicidad par.
  • ⚠️
    Raíces múltiples. Si \(f'(x^*)=0\), la convergencia baja a lineal — no cuadrática.
  • 💡
    Interpretación geométrica: \(x_{n+1}\) es donde la tangente a la curva en \(x_n\) corta el eje x.

Cuadrados Mínimos — Algoritmo paso a paso
Ajustar y = a₀ + a₁x a n pares de datos
  1. 1
    ARMAR LA TABLA: Columnas: \(x_i,\; y_i,\; x_i^2,\; x_i y_i\). Para grado 2, agregar \(x_i^3, x_i^4, x_i^2 y_i\).
  2. 2
    CALCULAR SUMAS: \(n,\; \sum x_i,\; \sum y_i,\; \sum x_i^2,\; \sum x_i y_i\).
  3. 3
    PLANTEAR SISTEMA NORMAL:
    $$\begin{pmatrix} n & \sum x_i \\ \sum x_i & \sum x_i^2 \end{pmatrix} \begin{pmatrix} a_0 \\ a_1 \end{pmatrix} = \begin{pmatrix} \sum y_i \\ \sum x_i y_i \end{pmatrix}$$
  4. 4
    RESOLVER: Fórmulas directas para recta:
    $$a_1 = \frac{n\sum x_i y_i - \sum x_i\sum y_i}{n\sum x_i^2 - \!\left(\sum x_i\right)^2}, \qquad a_0 = \bar{y} - a_1\bar{x}$$
  5. 5
    VERIFICAR: Calcular residuos \(r_i = y_i - f(x_i)\). Debe ser \(\sum r_i \approx 0\).
⚠️ CHECKLIST DE TRAMPAS — Cuadrados Mínimos
  • 🚨
    Confundir \(\left(\sum x_i\right)^2\) con \(\sum x_i^2\). Son distintos. \(\left(\sum x_i\right)^2\) es la suma total elevada al cuadrado; \(\sum x_i^2\) es la suma de los cuadrados uno a uno.
  • 🚨
    Usar \(N \geq n\). No se puede ajustar con grado mayor o igual a la cantidad de datos. Sería interpolación (o sistema incompatible).
  • ⚠️
    En linealización, olvidar transformar los datos. Si el modelo es \(y = ae^{bx}\), la variable a ajustar es \(\ln y\), no \(y\).
  • 💡
    Verificar \(\sum r_i \approx 0\). Si no se cumple, hay error en \(a_0\) o \(a_1\). Es la propiedad más útil para detectar errores.

Lagrange — Algoritmo paso a paso
Construir P(x) que pasa por n puntos, evaluar en x*
  1. 1
    VERIFICAR DATOS: Todos los \(x_i\) distintos. El polinomio es de grado \(n-1\).
  2. 2
    CALCULAR CADA \(L_i(x)\):
    $$L_i(x) = \frac{\displaystyle\prod_{\substack{j=0\\j\neq i}}^{n-1}(x - x_j)}{\displaystyle\prod_{\substack{j=0\\j\neq i}}^{n-1}(x_i - x_j)}$$
    Numerador: producto de \((x-x_j)\) para todos \(j \neq i\).
    Denominador: producto de \((x_i-x_j)\) para todos \(j \neq i\) — es una constante.
  3. 3
    ENSAMBLAR:
    $$P(x) = \sum_{i=0}^{n-1} y_i\, L_i(x)$$
  4. 4
    EVALUAR en \(x^*\): sustituir \(x = x^*\) en cada \(L_i\).
  5. 5
    VERIFICAR: \(P(x_i)\) debe ser \(= y_i\) para todo \(i\).
Para 3 puntos \((x_0,y_0),(x_1,y_1),(x_2,y_2)\):
\(L_0 = \dfrac{(x-x_1)(x-x_2)}{(x_0-x_1)(x_0-x_2)}\), \quad\) \(L_1 = \dfrac{(x-x_0)(x-x_2)}{(x_1-x_0)(x_1-x_2)}\), \quad\) \(L_2 = \dfrac{(x-x_0)(x-x_1)}{(x_2-x_0)(x_2-x_1)}\)
⚠️ CHECKLIST DE TRAMPAS — Lagrange
  • 🚨
    Olvidar un factor en el numerador o denominador. Cada \(L_i\) tiene exactamente \(n-1\) factores en cada parte.
  • 🚨
    Evaluar el denominador con \(x\) en vez de con \(x_i\). El denominador es CONSTANTE (solo números).
  • 💡
    Extrapolación: Si \(x^*\) está fuera del rango de datos, el resultado puede ser muy inexacto.

Newton — Diferencias Divididas + Horner
Tabla DD → coeficientes → evaluación anidada
  1. 1
    ORGANIZAR los \(n\) pares \((x_i,y_i)\) en la tabla.
  2. 2
    CONSTRUIR LA TABLA DD:
    $$f[x_i,x_{i+1}] = \frac{f[x_{i+1}] - f[x_i]}{x_{i+1} - x_i} \qquad f[x_i,x_{i+1},x_{i+2}] = \frac{f[x_{i+1},x_{i+2}] - f[x_i,x_{i+1}]}{x_{i+2}-x_i}$$
    Los coeficientes son la primera diagonal: \(a_k = f[x_0,\ldots,x_k]\).
  3. 3
    ESCRIBIR EL POLINOMIO:
    $$P(x) = a_0 + a_1(x-x_0) + a_2(x-x_0)(x-x_1) + \cdots$$
  4. 4
    EVALUAR CON HORNER (anidado):
    $$P(x^*) = a_0 + (x^*-x_0)\Big[a_1 + (x^*-x_1)\big[a_2 + (x^*-x_2)[\cdots]\big]\Big]$$
⚠️ CHECKLIST DE TRAMPAS — Diferencias Divididas
  • 🚨
    Dividir al revés. \(f[x_i,x_j] = (f[x_j]-f[x_i])/(x_j-x_i)\): el numerador y denominador van en el mismo orden (mayor menos menor).
  • 🚨
    Confundir el denominador. En \(f[x_i,\ldots,x_k]\), el denominador es \(x_k - x_i\) (último menos primero de los índices involucrados).
  • ⚠️
    Horner en orden invertido. Se evalúa de adentro hacia afuera, del coeficiente de mayor orden al menor.
  • 💡
    Para agregar un punto: solo se calcula una nueva columna en la tabla DD — gran ventaja sobre Lagrange.

Hermite

Spline de Hermite — cuando se conoce f'

Por tramo, se tienen 4 condiciones: \(S_i(x_i)=y_i\), \(S_i(x_{i+1})=y_{i+1}\), \(S_i'(x_i)=y_i'\), \(S_i'(x_{i+1})=y_{i+1}'\). Cada tramo se resuelve independientemente — sin el acoplamiento del spline natural.
⚠️ CHECKLIST DE TRAMPAS — Splines
  • 🚨
    Confundir \(n\) puntos con \(n-1\) tramos. Las incógnitas son \(4(n-1)\), no \(4n\).
  • 🚨
    Olvidar las condiciones de frontera natural \(S''=0\). Sin ellas el sistema está subdeterminado (faltarían 2 ecuaciones).
  • ⚠️
    Evaluar en el spline incorrecto. Verificar siempre en qué subintervalo \([x_i, x_{i+1}]\) cae el punto de evaluación.
